# Archive

Nothing in this directory is part of the active CodexPC runtime.

It exists only to preserve retired implementations, compatibility launchers and historical UI fixtures that can still be useful when comparing old behavior.

- `python-legacy/` — former Python connector implementation before the Go runtime became canonical.
- `legacy-launchers/` — retired startup helpers kept for reference only; do not use them for current installations.
- `legacy-binaries/` — historical binary/UI-era fixtures and regression material.

Current production code lives in `cmd/`, `internal/`, `frontend/` and `scripts/`.
